# 把入口接到你的工具

本模板不安装插件、不调用模型、不改全局配置。下面是接入方式，不是对各客户端的兼容性实测报告。

## 能读取本地文件的 Agent

先在一次普通对话中使用 README 的入口提示词，核对文件真的可读。再按所用客户端的现行文档，把这一小段入口放进它支持的持久规则位置。

Codex 类工具通常使用 AGENTS.md，Claude Code 类工具通常使用 CLAUDE.md；具体搜索范围、优先级和载入时机以客户端官方说明与实际读取结果为准。不要直接覆盖已有规则文件，也不要假定放在任意目录就会自动生效。

维护一份共享正文，在各工具入口中引用它；遇到不支持跨目录读取的工具，只提供本次任务所需的脱敏片段。不要复制访问凭证来绕过限制。

## 只能上传文件的聊天工具

手动提供所需的共享规则、项目卡和交接。明确这些文件对应哪个版本。新对话是否能访问旧附件、项目文件是否自动更新，都要在所用产品中检查，不能从一次读取成功推断。

## 新对话验收

让它先只读回答：

1. 读到的规则版本是什么？
2. 本次对应哪个项目，事实来源在哪里？
3. 上一份交接中哪些结果需要重新核对？
4. 当前允许做什么，哪些动作不能自行执行？

把答案与文件对照。有不一致先修入口或说明，不继续执行危险操作。“我已经记住”不是读取证据。
