# 用一次小任务试交接

先读[虚构项目卡](../examples/reading-list/project.md)和[虚构交接](../examples/reading-list/handoff.md)，了解填写方式。示例中提到的应用与测试结果没有在此仓库实现，不能拿来证明你的环境正常。

然后在你自己的可丢弃测试项目里做一次：

1. 填好项目卡，让第一个 Agent 只读核对入口、目标和限制。
2. 授权一个低风险的小改动，例如修改测试项目的一段说明。让它保留既有改动，并记录真正执行过的检查。
3. 让它按模板写交接：改了哪个文件、检查结果、未做的事，以及接手后的第一个动作。
4. 开一个新对话，提供共享入口和交接位置。不声称新对话已经收到旧上下文。
5. 让接手者先读实际文件，检查内容是否与交接一致，再按本次授权继续。

## 试一个不一致

在测试项目里，手动改变交接所指的一小段说明，再让第二个对话核对。期望它报告差异，而不是直接相信交接中的“已完成”。这才是在检查接手过程有没有核对事实。

## 记录结果

分别记下“模板填好”“入口读取成功”“真实文件核对通过”“任务接上”的结果。只做了第一步时，不标记后面几步成功。

你可以逐步加入自动通知，但仍要区分消息发送、接收、核对、写回、读回。自动化方案见[能力边界](limitations.md)。
